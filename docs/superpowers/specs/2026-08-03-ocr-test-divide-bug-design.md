# Open Code Review 测试缺陷设计

## 目标

为 Open Code Review 创建一个独立测试 PR，增加计算器的除法能力，并保留一个明确的边界缺陷，验证 OCR 能否识别运行时风险。

## 功能范围

- 在现有 `GET /api/calculate` 接口中支持 `operation=divide`。
- 正常输入 `a=10&b=2&operation=divide` 返回结果 `5`。
- 有意不处理 `b=0`，使除零请求触发 Go 运行时异常，作为 OCR 应发现的问题。
- 增加正常除法测试，但不增加除零测试，避免测试提前暴露并修复该缺陷。

## 预期验证

- `go test` 的正常功能测试能够覆盖除法成功路径。
- OCR 评审应指出除数为零时缺少校验，并建议返回客户端错误而不是触发 panic。
- 该修改仅用于测试，PR 不应合并到生产代码。
